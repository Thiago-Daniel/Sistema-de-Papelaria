# Sistema de Papelaria

Projeto desenvolvido para controle de estoque de papelaria utilizando PHP e MySQL.

## Funcionalidades

- Login de usuários
- Cadastro de usuários
- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Controle de estoque

## Tecnologias Utilizadas

- PHP
- MySQL
- HTML
- CSS
- XAMPP
